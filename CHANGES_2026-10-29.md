## Fix: an Explore result would not open ("View result" did nothing)
Cause: an Explore over many symbols (746 here, weekly, from 2000) made a result file with far too many rows for a phone to download and open.
Now: the runner stores Scan / Explore / Backtest results compressed (3-4 times smaller on real Explore data: 5.2 MB instead of 19 MB for 37,736 rows) and keeps the first 20,000 rows of an Explore in the
order your formula sorts them (the summary rows still count ALL rows; the Info tab says how many rows there were). The app opens both the new
and the old results (an old big Explore result is cut to its first 20,000 rows when opened, so the one you already have should open now),
and "View result" shows "Loading..." and, if something goes wrong, the reason in the panel instead of nothing.

## New: File -> "Sync data between devices..." (formulas, categories etc. on any device)
Your formulas, categories / watchlists / favorites, sheets and layouts, analysis settings and projects live inside each browser. The new window
saves them to your PRIVATE GitHub repo (file sync/app-data.json in the same repo and with the same token as "Run on GitHub") and loads them on
another device (or saves / opens a backup file instead). Loading can replace or "add what is missing" (formulas are joined, the newer edit wins)
and can be undone. The GitHub token and the AI key are never copied. A public repo is warned about.
New device: open the app -> File -> Sync data between devices... -> enter repo + token -> Load from GitHub -> Load now.
Files: js/sync-data.js, js/sync-ui.js (new); js/menu-bar.js, js/remote-analysis.js (small additions);
tests/sync-data-test.mjs, tests/browser/{sync-harness.html,sync-devices.mjs}

## New: public library - every device loads your formulas and categories by itself (build 2026-10-31b)
One-time set-up (about 5 minutes):
 1. On github.com create a new PUBLIC repository named  amibroker-shared-data  (tick "Add a README file"). Another name works if you change
    SHARED_DATA.repo in js/config.js.
 2. Make a new token (Settings > Developer settings > Fine-grained tokens): Repository access = BOTH amibroker-analysis-runner and
    amibroker-shared-data; permissions Contents = Read and write, Actions = Read and write.
 3. Install this zip (Render deploys it). On your phone: File > Sync data between devices... > paste the token > "Publish my data to everyone".
After that: anyone who opens the app gets the formulas, categories, watchlists, favorites, sheets, analysis settings and projects by themselves
(a new device loads and reloads once; changes you publish reach others within a minute or two). A device where someone changed something keeps
their own changes (only formulas are joined). Tokens, AI key, server settings are never published.
New: js/shared-data.js; changed: js/sync-data.js, js/sync-ui.js, js/config.js, js/app.js; tests: tests/sync-data-test.mjs, tests/browser/shared-library.mjs
